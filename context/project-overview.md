## Project Overview
- ABmarket is a storefront-facing web experience that presents partner/market pages for a business that sells products online.
- The app combines upstream website content with local transformations so users see consistent branding, links, styles, and CMS-managed contact data.
- In practice, this repository acts as a controlled rendering layer: it fetches upstream pages, sanitizes and reshapes them, caches results, and serves them through Next.js routes and APIs.
